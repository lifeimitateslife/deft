INSTALL DEFT ON MAC

DEFT is free and open source. This release is not Apple-notarized and has
no Apple-verified publisher. macOS may block its first launch.

1. Drag DEFT into Applications, then eject the disk image.
2. Open DEFT from Applications once. If macOS blocks it, dismiss the alert.
3. Open System Settings > Privacy & Security. Scroll down to Security.
4. Click Open Anyway for DEFT, authenticate if asked, then click Open.

This saves an exception for DEFT; later launches normally open directly.
Only approve the copy you downloaded from the official DEFT GitHub release.
An organization-managed Mac may not allow this exception.

BACKGROUND TRANSPARENCY

In DEFT Preferences, choose Material: Glass and adjust Background opacity.
Set Background blur to 0 for clear transparency, or increase its strength
for a softer background. Blur and opacity are independent. Enable
Translucent title bar to apply those settings to the DEFT title surface too.
Solid material and the Mac's Reduce Transparency accessibility setting
intentionally keep the background opaque. If native adjustable blur is
unavailable, DEFT falls back to the system's standard on/off blur control.
